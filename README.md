# LangGraph Chatbot with OpenRouter

A simple conversational AI chatbot built using:

- LangGraph
- LangChain
- OpenRouter
- OpenAI GPT-4o Mini
- MemorySaver for conversation memory

The chatbot stores conversation history using LangGraph memory and supports continuous chat sessions.

---

# Features

- Stateful conversation memory
- OpenRouter API integration
- LangGraph workflow
- CLI-based chat interface
- Easy to extend with tools and agents
